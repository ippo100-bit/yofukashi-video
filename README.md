# 夜更かしビデオ

契約中のサブスクを、深夜のレンタルビデオ店として3Dで歩いて選べるWebアプリです（three.js / 単一HTML）。

**公開ページ:** https://ippo100-bit.github.io/yofukashi-video/

## 在庫データ
- 自動入荷（キー不要）: iTunes（Apple）のジャンル別ランキングと AniList の公開データを、開くたびに取得します。
- TMDB 実データ（任意）: TMDB の API キーを入れると、日本の配信状況（JustWatch 提供）付きで入荷します。キーは各ブラウザの中にだけ保存され、このリポジトリには含まれません。
- 自動入荷モードの「配信サービス」表示はサンプルで、実際の配信状況とは異なります。

## 画像について
ジャケット画像はこのリポジトリには含まれていません。表示するときに各サービスの画像サーバーから読み込みます。著作権は各権利者に帰属します。
