キーの取り方（無料・5分）
  1. themoviedb.org で無料登録し、メールを確認
  2. 右上のアイコン →「設定」→「API」を開く
  3. 「APIキーを申請」→ 種類は「Developer（個人利用）」、用途に「個人の映画検索アプリ」などと入力
  4. 表示された「APIリードアクセストークン」（eyJ…で始まる長い文字列）をコピーして、上の欄に貼る
キーはこのブラウザにだけ保存されます。キーがあると、内蔵在庫の映画にも本物のポスターを付けます。Claude上で開いたページは外部通信が制限されるため、このHTMLを自分のPCやサーバーで開いたときに使えます。
操作方法

📱 左下をなぞって移動／右側をドラッグで見回す／ケースをタップで手に取る

💻 WASD・矢印キーで移動／ドラッグで見回す／クリックで手に取る

手に取ったケースはドラッグで回転、「裏面を見る」であらすじを確認できます。🛎 店員さんに相談すると、棚まで案内してくれます。

自動入荷は iTunes（Apple）と AniList の公開データを使います（届かない場合は Jikan / MyAnimeList）。通信できないとき（Claude上で開いたときなど）は内蔵在庫で営業します。配信サービスの表示は自動割り当てのサンプルで、実際の配信状況とは異なります。ポスターを読み込めない作品のジャケットは自動生成のイメージです。TMDBモードは TMDB（配信情報は JustWatch 提供）を利用します。This product uses the TMDB API but is not endorsed or certified by TMDB. 入口の外の景色は、Micael Widell さん撮影の写真（Wikimedia Commons、CC BY 3.0）を、少し暗くして表示しています。
